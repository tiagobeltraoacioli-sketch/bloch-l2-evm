# Solidity developer-node acceptance

`npm run test:solidity` compiles the checked-in `contracts/DeveloperCounter.sol`
with real solc-js and executes it through ethers against the isolated synthetic
Bloch developer node. Build the node as described in
[DEVNODE.md](../integrations/reth-execution/DEVNODE.md), then run:

```sh
cd wallets
npm ci --ignore-scripts
npm run test:solidity
```

Set `BLOCH_DEVNODE_BIN` to use another built executable. The test creates a new
temporary data directory, uses a public synthetic fixture key, and shuts down
its subprocesses. It does not connect to a public network or use real funds.

## Compiler and provenance

The exact dependency is `solc@0.8.30`; the test checks
`0.8.30+commit.73712a01.Emscripten.clang` and the installed compiler file SHA256.
The compiler settings are versioned in `contracts/compiler-settings.json`:
Cancun, optimizer enabled with 200 runs, no via-IR, no metadata bytecode hash,
and CBOR metadata enabled. Cancun is explicit because this compiler's default
is Prague. Compilation uses Standard JSON with an embedded local source and no
import callback; generated bytecode remains in memory.

Primary sources:

- [Official solc-js release 0.8.30](https://github.com/argotorg/solc-js/releases/tag/v0.8.30)
- [Solidity 0.8.30 compiler settings](https://docs.soliditylang.org/en/v0.8.30/using-the-compiler.html)
- [Official binary manifest](https://binaries.soliditylang.org/bin/list.json)
- [Official standalone compiler](https://binaries.soliditylang.org/bin/soljson-v0.8.30+commit.73712a01.js)

The standalone file's SHA256, verified against that manifest, is
`81475c98b6d2094a821fd9d7b6278556d8095ccc23e0b8a1029b1c08a89cd4b2`.
The npm package's compiler file has different JavaScript formatting and SHA256
`3bb491a777f76dff9b2fe73ce29ca20e21a971b59a2f2cf8f73415424f00be06`;
`package-lock.json` separately pins npm package integrity. These are not claimed
to be identical files. Qualification compared their embedded compiler payloads
and compiled this exact Standard JSON input with both: the complete parsed
compiler outputs matched, including ABI and creation/runtime bytecode. The
standalone download is a verification artifact outside the repository.

## Checked behavior

The acceptance passed on 2026-09-17: one test, 10.907 seconds. It checks:

- `ContractFactory.deploy(7)` and `setValue(42)` with ethers filling nonce,
  gas limit and fees automatically, without transaction overrides.
- Successful receipts, nonces 0 and 1, exact compiled runtime code, public
  getters and storage slot 0.
- The ABI-decoded `ValueChanged` event through both `Contract.queryFilter` and
  `provider.getLogs`, with indexed caller filtering and an absent-caller query.
- Exact `ValueTooLarge(1001, 1000)` revert data from real RPC `staticCall` and
  `estimateGas`; these failed simulations preserve storage and nonce 2.
- Orderly shutdown and reopening the same database and endpoint, followed by
  code, storage, getters, receipt, event and custom-error checks.

The revert checks are simulations, not mined failing transactions. This fixture
qualifies this compiler/configuration and contract; it does not establish all
Solidity versions, browser wallets, production L1 authentication, or crash
recovery. Existing ethers and MetaMask acceptance remain separate tests.
